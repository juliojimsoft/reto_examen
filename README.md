# Examen de Evaluación - Desarrollo Full Stack

Este repositorio contiene los recursos necesarios para la evaluación técnica en desarrollo Full Stack, incluyendo pruebas de SQL, desarrollo backend con Spring Boot y una sección en proceso para el frontend.

---

## 1. Examen de Base de Datos SQL

- **Motor de base de datos:** SQL Server  
- **Backup:** Se encuentra en la carpeta `db_personal.bak`.
- **Scripts SQL:** El archivo `.sql` incluye:
  - Sentencias para crear la base de datos.
  - Creación de tablas.
  - Procedimientos almacenados.

---

## 2. Desarrollo Backend

- **Ubicación:** Carpeta `Reto Backend`
- **Inicializador:** El archivo `reto_examen.zip` contiene la estructura base de un proyecto Spring Boot.
- **Proyecto:** El código fuente está descomprimido en la carpeta `reto_examen`.
- **Gestor de dependencias:** Maven (`pom.xml` incluido).
- **Conexión a base de datos:**  
  Configurada en `application.properties` para utilizar una herramienta cloud en entorno de desarrollo.

## Recomendaciones

- Asegúrate de tener instalado:
  - SQL Server o una instancia compatible.
  - Java 17+.
  - Maven 3.8+.
  - IDE como IntelliJ o VS Code.
- Importa el proyecto backend como un proyecto Maven.
